
💻 Digital Banking Platform – UI Design (React + Tailwind CSS)

A clean and responsive UI design project built using React.js and Tailwind CSS, focused on modern design principles and smooth component-based structure.

This interface showcases Prospective Customer Segmentation for a Digital Banking Platform, highlighting how users can be categorized into different groups — Satisfied, Underserved, and Underbanked.

🧠 Features:

Fully responsive and accessible layout

Built with reusable React components

Styled with Tailwind CSS for scalability and speed

Smooth design inspired by real-world fintech dashboards

🚀 Tech Stack:

React.js

Tailwind CSS
